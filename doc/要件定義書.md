# 1. システム概要

## 1.1 システム名

**見積書作成ツール（Estimate Tool）**

------------------------------------------------------------------------

## 1.2 システム概要

本システムは、見積書作成業務および管理台帳更新業務を効率化するための
Windows デスクトップアプリケーションである。

業務で使用される PDF・Excel
ファイルから必要情報を抽出し、見積書の作成、管理台帳の更新、および
OneDrive 上のファイル管理を自動化する。

また、一部帳票では AI（OpenAI Vision）を利用して PDF
の内容を解析し、必要な情報を抽出する。

------------------------------------------------------------------------

## 1.3 システムの特徴

本システムでは以下の特徴を持つ。

-   PDFから必要情報を自動抽出
-   文字情報を持つPDFを自動解析
-   画像形式のPDFをAIで自動解析
-   Excelへの転記を自動化
-   OneDrive管理台帳を直接更新
-   OpenAI Visionによる帳票解析
-   PDF形式を意識せず利用可能
-   長い成果物名や改行された成果物を見積書の表示領域に合わせて整理
-   処理結果の詳細を4業務で統一表示

------------------------------------------------------------------------

# 2. 開発背景

従来の見積書作成業務では、

-   PDFの内容確認
-   Excelへの転記
-   管理台帳更新
-   見積書作成

をすべて担当者が手作業で実施していた。

そのため、

-   転記ミス
-   入力漏れ
-   作業時間の増加
-   管理台帳更新漏れ

などの問題が発生していた。

これらの課題を解決するため、本システムを開発する。

------------------------------------------------------------------------

# 3. 開発目的

本システムの目的は以下とする。

-   見積書作成業務の自動化
-   転記ミス削減
-   作業時間短縮
-   管理台帳更新の効率化
-   OneDriveとの連携による最新データ管理
-   AIを活用した情報抽出

# 8. 機能要件

## 8.1 特調TB

### 入力

-   業務計画書（PDF）
-   管理台帳（OneDrive）

### 処理

-   PDF読込
-   PDF形式判定
-   文字PDFの場合はpdfplumberで解析
-   画像PDFの場合はOpenAI Visionで解析
-   必要情報抽出
-   見積／請求番号取得
-   見積／請求番号が未採番の場合は自動採番
-   管理台帳更新
-   管理台帳の案件名にはPDFの件名を登録
-   見積書作成
-   成果物番号が本文と同一行または独立行で抽出されるPDFの両方に対応
-   改行された成果物を同一成果物として保持
-   同名成果物で2行目の内容が異なる場合、2行目を識別情報として使用
-   2行表示しても成果物欄が7行以内の場合は、同名成果物の2行目をNoなしの継続行として表示
-   2行表示すると7行を超える場合は、1行目と識別に必要な2行目を組み合わせ、必要に応じてAIで1行に短縮
-   AI短縮に失敗した場合でも成果物を欠落させず原文を使用
-   必要項目を複数取得できない等、PDFフォーマットが特調TBの対応形式と異なる可能性がある場合は確認メッセージを表示

### 出力

-   見積書（Excel）
-   更新済み管理台帳

#### 管理台帳更新仕様

-   業務計画書Noの重複チェックを行う。
-   重複している場合は登録を中止しエラーとする。
-   案件名には業務計画書の「件名」を登録する。
-   見積／請求番号が未設定の場合は、対象シートの最大番号＋1を採番する。
-   発行日・発行者を自動登録する。

## 8.3 TG

### 入力

-   PDF

### 処理

-   OpenAI Vision解析
-   必要情報抽出
-   Excel生成
-   管理台帳更新
-   MSR管理台帳をExcelで開けない場合、外部リンク情報の一部に不整合がある可能性を案内
-   台帳Open失敗時は、OneDrive上の台帳をExcelで直接開き、必要に応じて修復・上書き保存した後に再実行する確認手順を表示
-   外部リンクの存在自体を異常とは断定しない

### 出力

-   見積書（Excel）
-   更新済み管理台帳

------------------------------------------------------------------------

### 共通ダイアログ

以下を統一デザインで表示する。

-   実行確認
-   完了
-   情報
-   警告
-   エラー
-   処理結果詳細

特調TB、特調TB以外、TG、MSRの処理結果一覧は、行をダブルクリックすると「処理結果詳細」を表示する。

処理結果詳細には、業務に応じて識別番号、見積／請求番号、結果、詳細メッセージを表示する。TG・MSRを含む4業務で
`CustomMessageDialog` を使用し、デザインを統一する。

------------------------------------------------------------------------

### ユーザーマスタ

管理台帳更新時に使用する担当者情報を取得する。

取得項目

-   氏名
-   メールアドレス
