# 2. システム概要

## 2.1 目的

本システムは、業務計画書PDFや見積書発行依頼Excelなどの入力ファイルから、見積書作成に必要な情報を取得し、見積書Excel・PDFの作成および管理台帳への登録を自動で行うWindowsデスクトップアプリケーションである。

利用者は、画面上部の共通入力欄に入力フォルダ、出力フォルダ、管理台帳URL、利用者一覧URLを設定し、対象業務のタブから「一括実行」ボタンを押す。

対象ファイルの検索、入力内容の読み取り、PDF形式の判定、必要情報の抽出、
管理台帳更新、見積書作成、PDF出力および処理結果表示までを連続して実行する。

PDFに文字情報が存在する場合は通常解析を行い、
文字情報を取得できない画像形式のPDFについては AI（OpenAI
Vision）による画像解析へ自動的に切り替える。

## 2.2 対象業務

  タブ         対象業務                     主な入力
  ------------ ---------------------------- ---------------------
  特調TB       特調TB案件の見積書作成       業務計画書PDF
  特調TB以外   特調TB以外案件の見積書作成   業務計画書PDF
  TG           TG案件の見積書作成           TG用PDF等
  MSR          MSR案件の見積書作成          見積書発行依頼Excel

### 6.1.1 成果物の長文・改行対応

特調TBの成果物欄は、PDF上の成果物番号（①～⑳）を基準として論理的な成果物単位に解析する。

-   `① 成果物名` のように番号と本文が同一行にある形式に対応する。
-   `②`
    のように番号のみが独立した行にある場合は、次の本文行を当該成果物の1行目として扱う。
-   同一成果物内の改行は、同一成果物の継続内容として保持する。
-   番号のみで本文が存在しない空のテンプレート行は成果物として追加しない。
-   元の成果物内容は保持し、見積書表示用の名称を別途生成する。

### 6.1.2 同名成果物の表示

成果物の1行目が同じ名称で、2行目の内容が異なる場合は、2行目を識別情報として使用する。

見積書の成果物欄が7行以内に収まる場合は、同名成果物のみ2行表示とする。

``` text
1  設計問題点の調査、展開
   市場不具合の確認・分類・判定根拠整理

2  市場不具合 発生箇所の確認

3  設計問題点の調査、展開
   設計不具合の確認・分類・判定根拠整理
```

2行目の継続行には成果物Noを表示しない。

### 6.1.3 7行超過時のAI短縮

同名成果物の2行表示によって見積書の成果物欄（最大7行）を超える場合は、2行目を別行として出力せず、1行目と識別に必要な2行目の内容を組み合わせて1成果物1行へ短縮する。

短縮処理は既存の成果物名短縮処理を利用し、表示可能な場合は原文を使用し、必要な場合のみ辞書・キャッシュ・OpenAI
APIによるAI短縮を使用する。

AI短縮に失敗した場合は原文を使用し、成果物自体を欠落させない。

### 6.1.4 特調TB PDFフォーマット違い警告

特調TBとして必要な項目を複数取得できない場合など、選択されたPDFが対応フォーマットと異なる可能性があると判定した場合は、通常の抽出エラーではなくフォーマット確認メッセージを表示する。

表示内容には次を含む。

-   「PDFのフォーマットが対応形式と異なる可能性があります。」
-   処理種別：特調TB
-   特調TBの業務委託計画書フォーマットであることの確認依頼
-   取得できなかった項目
-   対象PDF名

フォーマット違いを断定せず、「可能性があります」として利用者へ確認を促す。

### 6.1.5 成果物名称と備考の分離

特調TBの成果物表では、「成果物名称 / Name of output(s)」列と「備考（数量／サイズ指定など） / Remarks (Volume/Size etc.)」列を別項目として扱う。

- 文字情報を持つPDFでは、`pdfplumber` で取得した表構造から「成果物名称」列を特定し、当該列の文字だけを成果物として取得する。
- 「備考」列に記載された「一式」「一式／一任」「1/A3」「数量、サイズ指定無」等は成果物へ含めない。
- 表構造から成果物を取得できない場合は、既存のテキスト解析方式へフォールバックする。
- 画像形式のPDFでは OpenAI Vision の抽出条件により「成果物名称」列だけを取得し、「備考 / Remarks」列は成果物へ含めない。
- 成果物名称セル内に改行がある場合は同一成果物として保持し、既存の長文・改行・同名成果物表示処理へ引き渡す。

これにより、文字PDFと画像PDFの双方で成果物名称と備考を分離し、見積書には成果物名称のみを出力する。

### 6.4.1 MSR管理台帳Openエラー案内

MSR管理台帳をMicrosoft Excelで開けない場合は、Excel
COMの例外メッセージだけを表示せず、利用者が確認すべき内容を分かりやすく表示する。

過去事例として、管理台帳内部に外部ファイルを参照する「外部リンク」情報が残り、その外部リンク情報の一部にExcelが不整合を検出したことで
`Workbooks.Open` が失敗したケースがある。

このため台帳Open失敗時は、次の内容を案内する。

1.  OneDrive上のMSR管理台帳をExcelで直接開く。
2.  「ファイルに問題が見つかりました」等の修復メッセージが表示された場合は修復する。
3.  修復後、Excelファイルを上書き保存する。
4.  保存後、見積書作成ツールでもう一度実行する。

外部リンクが存在するだけでは異常ではないため、「外部リンク情報の一部にExcelが不整合を検出している可能性があります」と表示する。

また、ファイルがExcelで開かれている場合、アクセス権がない場合、Excel側で別の問題が発生している場合もOpenに失敗する可能性がある旨を併記する。

## 10.2 外部連携エラー

  条件                処理
  ------------------- ------------------------------

  401／403            認証または権限エラー
  404                 URLまたは対象ファイル不明
  412                 ETag競合として更新中止
  423                 一定回数リトライ後に失敗
  アップロード失敗    失敗として表示

## 10.3 ファイル処理エラー

  ---------------------------------------------------------------------------------------------------------------------
  条件                                処理
  ----------------------------------- ---------------------------------------------------------------------------------
  文字PDF解析失敗                     対象ファイルを失敗として表示

  PDFフォーマット不一致の可能性       

  MSR管理台帳Open失敗                 外部リンク情報の不整合等の可能性と、Excelでの修復・上書き保存・再実行手順を表示
  ---------------------------------------------------------------------------------------------------------------------

# 11. 非機能設計

## 11.1 操作性

-   初めて使用する利用者でも、一括実行まで迷わない画面構成とする。
-   入力項目は画面上部へ集約する。
-   タブ切替時に対象業務が明確に分かるタイトルを表示する。
-   処理中のファイル名と進捗率を表示する。
-   完了後に成功・NG・失敗件数を表示する。
-   4業務すべてで処理結果行をダブルクリックすると統一デザインの処理結果詳細を表示する。

## 11.2 性能

-   複数ファイルを連続処理できること。
-   時間のかかる処理はWorkerスレッドで実行すること。
-   画面操作が固まらないこと。
-   外部APIの応答待ちにはタイムアウトまたはリトライを設定すること。

## 11.3 セキュリティ

-   APIキーや認証情報をソースコードへ記載しない。
-   `.env` は公開リポジトリへコミットしない。
-   Microsoft Graphは必要な権限のみ使用する。
-   認証トークンは外部へ表示しない。
-   エラーログへAPIキーを出力しない。

## 11.4 保守性

-   Reader、Writer、Cloud、AI、Excel処理を分離する。
-   業務別処理をタブおよびWorker単位で分離する。
-   テンプレートパスはTemplateResolverで管理する。
-   共通Excel操作はExcelAutomationHelperへ集約する。
-   メッセージ表示はCustomMessageDialogへ集約する。
